## Featured Work

**Atlasonography — offline ultrasound diagnostic AI (Celestia AI)**
*NASA x ASU · PyTorch · UNET · TFLite*

> UNET segmentation model for offline/low-connectivity diagnostic ultrasound, built for space health applications. **91% sensitivity**, quantized to **34.2MB**, exported to `.tflite` for on-device inference. Provisional patent filed — code is not public.

---

**SnipGen — CRISPR guide RNA design platform**
*Python · Flask · scikit-learn*

> On-target scoring model trained on 5,310 real CRISPR screen guides (Doench 2016 / Azimuth). Spearman correlation **0.556**, in line with the published Azimuth benchmark. Genome-wide off-target scoring via CRISPOR, with ClinVar flags on clinically significant genes. Live and deployed.

→ [github.com/lakshya-dharwal/snipgen](https://github.com/lakshya-dharwal/snipgen) · [Live demo](https://snipgen-g4on.vercel.app)

---

**MTAP Scout — bladder cancer genomics candidate reviewer**
*XGBoost · SHAP · scikit-learn*

> ML model for reviewing bladder cancer genomic candidates. Ablation study shows AUC drop from **0.97 to 0.78** when key features are removed, real evidence the model learned signal rather than shortcuts. In active review with IDEAYA Biosciences' bioinformatics team.

→ [github.com/lakshya-dharwal/mtap-scout](https://github.com/lakshya-dharwal/mtap-scout)
